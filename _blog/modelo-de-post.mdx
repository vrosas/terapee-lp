Este arquivo é um rascunho de referência: rascunhos aparecem no `npm run dev`, mas não vão para o site publicado. A primeira frase do post deve responder logo à pergunta de quem chegou pelo Google.

## Use H2 para as seções principais

Cada H2 entra automaticamente no índice "Neste artigo" na lateral, quando o post tem três ou mais. Escreva parágrafos curtos, de duas a quatro frases.

Faça links internos para as páginas do site sempre que fizer sentido, por exemplo para a [agenda com lembretes no WhatsApp](/funcionalidades/lembretes-whatsapp) ou para a [calculadora de precificação](/ferramentas/calculadora-de-precificacao).

### H3 para subtópicos

- Listas ajudam a escanear o texto.
- Um item por ideia.
- **Negrito** só no que importa.
